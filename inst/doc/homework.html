Beta(a,b)分布的密度函数\(f(x)=\frac{\Gamma(a+b)}{\Gamma(a)\Gamma(b)}x^{a-1}(1-x)^{b-1},\ 0<x<1\), 令\(g(x)=1\), 则可以取\(M = \max\ f(x)\), 而当\(a>1,\ b>1\)时beta(a,b)分布的密度函数最大值在众数\(\frac{a-1}{a+b-2}\)处取到，对于\(a=b=1\)，可以采取遍历的方式取最大值：

set.seed(123)
n = 1000; i = 0; k = 0
generate_beta <- function(n, a, b){
  if (a>1 && b>1) {
    mode = (a-1)/(a+b-2)
    M = dbeta(mode, a, b)
  }else{
    M = max(dbeta(seq(0.01, 0.99, 0.01), a, b)) + 0.1
  }
  samples = numeric(n)
  while (i < n) {
    x = runif(1)
    k = k + 1
    u = runif(1)
    if (u <= dbeta(x, a, b)/M) {
      i = i + 1
      samples[i] = x
    }
  }
  return(samples)
}

stat_infer <- function(data){
  a = data$a; b = data$b; X = data$X; m_j = data$m_j; K = length(X)
  Pj = (exp(-a) - exp(-b))/(1 - exp(-1))         
  r_bar = s2 = numeric(K)
  for(j in 1:K){
    rj = (1 - exp(-1))/(1 + X[[j]]^2)
    r_bar[j] = mean(rj)
    s2[j] = var(rj)

  var_hat = sum(Pj^2 * s2 / m_j)

}

You should output the 6 numbers to a 3×2 table (column names: Bonferroni correction, B-H correction; row names: FWER, FDR, TPR). Comment the results.

Answer

infer_multi <- function(N = 1000, m0 = 950, alpha = 0.1, m = 10000, seed = 123, out_file = "multi_step1.rds"){
  set.seed(seed)
  fwer_b = fwer_bh = fdr_b = fdr_bh = tpr_b = tpr_bh = 0
  m1 = N - m0
  for(rep in 1:m){
    p = c(runif(m0), rbeta(m1, 0.1, 1)) 
    padj_b  = p.adjust(p, "bonferroni")
    padj_bh = p.adjust(p, "BH")
    for (padj in list(padj_b, padj_bh)) {
      rej <- padj <= alpha
      R = sum(rej); V = sum(rej[1:m0]); S = sum(rej[(m0+1):N])
      fwer = as.integer(V > 0)
      fdr = if (R > 0) V / R else 0
      tpr = S / m1
      if (identical(padj, padj_b)) { fwer_b = fwer_b + fwer; fdr_b = fdr_b + fdr; tpr_b = tpr_b + tpr }
      else                         { fwer_bh= fwer_bh+ fwer; fdr_bh= fdr_bh+ fdr; tpr_bh= tpr_bh+ tpr }
      }
    }
    res <- matrix(c(fwer_b, fwer_bh,  # FWER
                    fdr_b,  fdr_bh,   # FDR
                    tpr_b,  tpr_bh),  # TPR
                  nrow=3, byrow=TRUE) / m
    dimnames(res) <- list(c("FWER","FDR","TPR"),
                          c("Bonferroni","B-H"))
    saveRDS(list(table=res, params=par), out_file)
    invisible(res)
}

mc_boot_ci <- function(m = 1e4, n = 50, B = 1000, mu = 0) {
  res <- list(
    normal = c(hit = 0, missL = 0, missR = 0),
    basic  = c(hit = 0, missL = 0, missR = 0),
    perc   = c(hit = 0, missL = 0, missR = 0)
  )

  for (i in 1:m) {
    x = rnorm(n, mean = mu, sd = 1)
    theta_hat = mean(x)
    boot_means = replicate(B, mean(sample(x, n, replace = TRUE)))
    se_boot = sd(boot_means)

    q = quantile(boot_means, c(0.025, 0.975))
    qL = q[1]; qU = q[2]

    ## (1) bootstrap-normal CI
    z = qnorm(0.975)
    ciN_L = theta_hat - z * se_boot
    ciN_U = theta_hat + z * se_boot

    ## (2) basic CI
    ciB_L = 2*theta_hat - qU
    ciB_U = 2*theta_hat - qL

    ## (3) percentile CI
    ciP_L = qL
    ciP_U = qU

      if (mu < ciL) {

      }

    update(ciB_L, ciB_U, "basic")
    update(ciP_L, ciP_U, "perc")
  }
  out <- sapply(res, function(v) v / m)
  rownames(out) <- c("coverage", "miss_left", "miss_right")

\[ K(r,s) = \mathbf{I}(s\neq r)\,\alpha(r,s)\,g(s\mid r) \;+\; \mathbf{I}(s=r)\Big[\,1-\!\int \alpha(r,s)\,g(s\mid r)\,\Big]. \]

我们首先需要证明 \[ f(s)\,K(r,s) \;=\; f(r)\,K(s,r). \]

对 \(s\neq r\)， \[ \begin{aligned} f(s)\,K(r,s) &= f(s)\,\alpha(r,s)\,g(s\mid r) \\ &= f(s)\,g(s\mid r)\, \min\!\left\{1,\ \frac{f(r)\,g(s\mid r)}{f(s)\,g(r\mid s)}\right\} \\ &= \min\!\big\{f(s)\,g(s\mid r),\ f(r)\,g(r\mid s)\big\}. \end{aligned} \]

同理， \[ \begin{aligned} f(r)\,K(s,r) &= f(r)\,\alpha(s,r)\,g(r\mid s) \\ &= f(r)\,g(r\mid s)\, \min\!\left\{1,\ \frac{f(s)\,g(r\mid s)}{f(r)\,g(s\mid r)}\right\} \\ &= \min\!\big\{f(r)\,g(r\mid s),\ f(s)\,g(s\mid r)\big\}. \end{aligned} \]

因此有\(f(s)\,K(r,s)=f(r)\,K(s,r)\) 成立。

接着，两边对 \(s\) 积分： \[ \int f(s)\,K(r,s)\,ds = \int f(r)\,K(s,r)\,ds = f(r)\int K(s,r)\,ds. \]

因为 \(K(\cdot,r)\) 是转移核，\(\int K(s,r)\,ds=1\)，于是有 \[ \int f(s)\,K(r,s)\,ds \;=\; f(r). \]

得证。

Gelman.Rubin <- function(psi) {
  psi = as.matrix(psi)
  n = ncol(psi)
  k = nrow(psi)
  psi.means = rowMeans(psi)
  B = n * var(psi.means) 
  psi.w = apply(psi, 1, "var")
  W = mean(psi.w)          
  v.hat = W * (n - 1) / n + (B / n)
  r.hat = v.hat / W  
  return(r.hat)
}

Question

Refer to the Bayesian prediction application in Example 11.3, with the Geometric\((p)\) survival model.
Prove that the derived parameter \(\psi(p) = \frac{p}{1-p}\) does not depend on attained age of the individual in this model.

Answer

在几何生存模型中，个体生存时间为\(k\)的概率为

\[ \Pr(T = k) = p^{k}(1-p), \quad k = 0,1,2,\ldots, \]

其中\(0 < p < 1\)。

给定个体已经活到了时间\(a\),即\(T \ge a\)时，记它的未来生存时间为$R_a := T-a. $ 对任意 \(k = 0,1,2,\ldots\)，有 \[ \Pr(R_a = k) = \Pr(T = a + k \mid T \ge a) = \frac{\Pr(T = a + k,\, T \ge a)}{\Pr(T \ge a)} = \frac{\Pr(T = a + k)}{\Pr(T \ge a)}. \]

由\(T \sim \text{Geometric}(p)\)知，\(\Pr(T = a + k) = p^{a+k}(1-p),\) 又有 \[ \Pr(T \ge a) = \sum_{j=a}^{\infty} \Pr(T=j) = \sum_{j=a}^{\infty} p^{j}(1-p) = (1-p)\,p^{a} \sum_{j=0}^{\infty} p^{j} = (1-p)\,p^{a} \cdot \frac{1}{1-p} = p^{a}. \] 代入得 \[ \Pr(R_a = k) = \frac{p^{a+k}(1-p)}{p^{a}} = p^{k}(1-p), \quad k = 0,1,2,\ldots \]

这说明对任意给定时间\(a\)，\(R_a\) 的分布与\(T\)相同，仍然是参数为\(p\)的几何分布，与\(a\) 无关。

又因

\[ \psi(p) = \frac{p}{1-p} = \sum_{k=0}^{\infty} k\,p^k(1-p) = \mathbb{E}[T], \]

由于对任意\(a\)，\(R_a\) 仍服从 Geometric\((p)\)分布，因此 \[ \mathbb{E}[T-a \mid T \ge a] = \mathbb{E}[R_a] = \frac{p}{1-p}. \]

它只依赖于参数 \(p\)，与生存年龄 \(a\) 无关。

综上，在 Geometric\((p)\) 生存模型下，\(\psi(p) = \frac{p}{1-p}\)与个体当前年龄 \(a\) 无关。

Question1:

设 \(X_1, \dots, X_n \overset{iid}{\sim} Exp(\lambda)\)。因为某种原因，只知道 \(X_i\) 落在区间 \((U_i, V_i)\)内，其中\(U_i < V_i\)非随机。分别直接极大化似然函数和 EM 算法求解 \(\lambda\) 的 MLE，并证明 EM 算法收敛于观测数据的 MLE，且收敛有线性速度。

Answer1：

指数分布的累积分布函数为 \(F(x) = 1 - e^{-\lambda x}\)。观测数据为区间 \((U_i, V_i)\)，则似然函数为： \[ L(\lambda) = \prod_{i=1}^n P(u_i < X_i < v_i) = \prod_{i=1}^n \left( e^{-\lambda u_i} - e^{-\lambda v_i} \right) \]

对数似然函数 \(l(\lambda)\) 为： \[ l(\lambda) = \sum_{i=1}^n \ln \left( e^{-\lambda u_i} - e^{-\lambda v_i} \right) \]

为了求 MLE，令导数为 0： \[ \frac{\partial l(\lambda)}{\partial \lambda} = \sum_{i=1}^n \frac{\frac{\partial}{\partial \lambda}(e^{-\lambda u_i} - e^{-\lambda v_i})}{e^{-\lambda u_i} - e^{-\lambda v_i}} = \sum_{i=1}^n \frac{-u_i e^{-\lambda u_i} - (-v_i e^{-\lambda v_i})}{e^{-\lambda u_i} - e^{-\lambda v_i}} = 0 \]

整理得直接 MLE 满足的方程： \[ \sum_{i=1}^n \frac{v_i e^{-\lambda v_i} - u_i e^{-\lambda u_i}}{e^{-\lambda u_i} - e^{-\lambda v_i}} = 0 \]

下面考虑EM算法，有E步 (Expectation Step): 计算完全数据充分统计量的条件期望。对于指数分布，核心是计算 \(X\) 在区间 \((u, v)\) 上的条件期望： \[ E[X_i | u_i < X_i < v_i; \lambda^{(t)}] = \frac{\int_{u_i}^{v_i} x \lambda e^{-\lambda x} dx}{\int_{u_i}^{v_i} \lambda e^{-\lambda x} dx} \] 利用分部积分法可得： \[ \hat{x}_i^{(t)} = \frac{1}{\lambda^{(t)}} + \frac{u_i e^{-\lambda^{(t)} u_i} - v_i e^{-\lambda^{(t)} v_i}}{e^{-\lambda^{(t)} u_i} - e^{-\lambda^{(t)} v_i}} \]

M步利用填补后的数据更新参数。指数分布的 MLE 为样本均值的倒数：

\[ \lambda^{(t+1)} = \frac{n}{\sum_{i=1}^n \hat{x}_i^{(t)}} \] 即迭代公式为： \[ \frac{n}{\lambda^{(t+1)}} = \sum_{i=1}^n \left( \frac{1}{\lambda^{(t)}} + \frac{u_i e^{-\lambda^{(t)} u_i} - v_i e^{-\lambda^{(t)} v_i}}{e^{-\lambda^{(t)} u_i} - e^{-\lambda^{(t)} v_i}} \right) \]

当 EM 算法收敛时，参数不再变化，即 \(\lambda^{(t+1)} = \lambda^{(t)} = \hat{\lambda}\)。 将 \(\hat{\lambda}\) 代入 M 步的迭代公式中：

\[ \frac{n}{\hat{\lambda}} = \sum_{i=1}^n \left( \frac{1}{\hat{\lambda}} + \frac{u_i e^{-\hat{\lambda} u_i} - v_i e^{-\hat{\lambda} v_i}}{e^{-\hat{\lambda} u_i} - e^{-\hat{\lambda} v_i}} \right) \]

将右侧求和展开： \[ \frac{n}{\hat{\lambda}} = \sum_{i=1}^n \frac{1}{\hat{\lambda}} + \sum_{i=1}^n \frac{u_i e^{-\hat{\lambda} u_i} - v_i e^{-\hat{\lambda} v_i}}{e^{-\hat{\lambda} u_i} - e^{-\hat{\lambda} v_i}} \]

注意到 \(\sum_{i=1}^n \frac{1}{\hat{\lambda}} = \frac{n}{\hat{\lambda}}\)，因此方程两边消去该项，得到： \[ 0 = \sum_{i=1}^n \frac{u_i e^{-\hat{\lambda} u_i} - v_i e^{-\hat{\lambda} v_i}}{e^{-\hat{\lambda} u_i} - e^{-\hat{\lambda} v_i}} \]

将分子符号反转得到： \[ \sum_{i=1}^n \frac{v_i e^{-\hat{\lambda} v_i} - u_i e^{-\hat{\lambda} u_i}}{e^{-\hat{\lambda} u_i} - e^{-\hat{\lambda} v_i}} = 0 \]

此方程与MLE方法的 Score Equation 完全一致。 因此，EM 算法的收敛点 \(\hat{\lambda}\) 满足似然方程，即 EM 算法收敛于观测数据的 MLE。

newton_raphson <- function(u, v, lambda_start, tol, max_iter) {
  lambda <- lambda_start
  path <- c(lambda)
  for (i in 1:max_iter) {
    delta <- v - u
    term1 <- -u
    term2 <- delta / (exp(lambda * delta) - 1)
    score <- sum(term1 + term2)
    hessian <- -sum((delta^2 * exp(lambda * delta)) / (exp(lambda * delta) - 1)^2)
    lambda_new <- lambda - score / hessian
    path <- c(path, lambda_new)
    if (abs(lambda_new - lambda) < tol) {
      return(list(est = lambda_new, iter = i, path = path, converged = TRUE))
    }
    lambda <- lambda_new
  }
  return(list(est = lambda, iter = max_iter, path = path, converged = FALSE))
}

Question

Make a faster version of chisq.test() that only computes the chi-square test statistic when the input is two numeric vectors with no missing values. You can try simplifying chisq.test() or by coding from the mathematical definition (http://en.wikipedia.org/wiki/Pearson%27s_chi-squared_test).

Answer

fast_chisq <- function(x, y) {
  stopifnot(is.numeric(x), is.numeric(y))
  stopifnot(length(x) == length(y))
  
  tab = table(x, y)
  rs = rowSums(tab)
  cs = colSums(tab)
  n = sum(tab)
  E = outer(rs, cs, "*") / n
  X2 = sum((tab - E)^2 / E)
  return(X2)
}

fast_table <- function(x, y) {
  ix = x - min(x) + 1
  iy = y - min(y) + 1

Question1

Write an Rcpp function for Exercise 11.8 (page 334, Statistical Computing with R, 2nd edition).

Rao [232, Sec. 5g] presented an example on genetic linkage of 197 animals in four categories (also discussed in [70, 110, 179, 280]). The group sizes are (125,18,20,34). Assume that the probabilities of the corresponding multinomial distribution are \[(\frac{1}{2}+\frac{\theta}{4},\,\frac{1-\theta}{4},\,\frac{1-\theta}{4},\, \frac{\theta}{4}).\] Estimate the posterior distribution of θ given the observed sample, using one of the methods in this chapter.

Answer

我们采用Metropolis-Hastings采样方法估计$，先给出MH采样方法的R语言版本:

n_obs = c(125, 18, 20, 34)

logpost_theta <- function(theta, n = n_obs) {
  if (theta <= 0 || theta >= 1) return(-Inf)
  p1 = 0.5 + theta / 4
  p2 = (1 - theta) / 4
  p3 = (1 - theta) / 4
  p4 = theta / 4
  l = sum(n * log(c(p1, p2, p3, p4)))
  if (any(c(p1, p2, p3, p4) <= 0)) return(-Inf)
  return(l)
}

rw_theta_R <- function(N, theta0, w, n = n_obs) {
  theta = numeric(N)
  theta[1] = theta0
  accept = 0L
  for (i in 2:N) {
    y = theta[i - 1] + runif(1, -w, w)
    if (y <= 0 || y >= 1) { 
      theta[i] = theta[i - 1]
      next
    }
    logalpha = logpost_theta(y, n) - logpost_theta(theta[i - 1], n)
    if (log(runif(1)) < logalpha) {
      theta[i] = y
      accept = accept + 1L
    } else {
      theta[i] = theta[i - 1]
    }
  }
  list(theta = theta, acc_rate = accept / (N - 1))
}

再编写cpp版本：

#include <Rcpp.h>
using namespace Rcpp;

double logpost_theta_cpp(double theta, const NumericVector &n) {
  if (theta <= 0.0 || theta >= 1.0) return R_NegInf;
  
  double p1 = 0.5 + theta / 4.0;
  double p2 = (1.0 - theta) / 4.0;
  double p3 = p2;
  double p4 = theta / 4.0;
  
  if (p1 <= 0.0 || p2 <= 0.0 || p3 <= 0.0 || p4 <= 0.0)
    return R_NegInf;
  
  double loglik = n[0] * std::log(p1)
    + n[1] * std::log(p2)
    + n[2] * std::log(p3)
    + n[3] * std::log(p4);
    return loglik;
}

// [[Rcpp::export]]
List rw_theta_cpp(int N, double theta0, double w, NumericVector n) {
  NumericVector theta(N);
  theta[0] = theta0;
  int accept = 0;
  
  for (int i = 1; i < N; ++i) {
    double y = theta[i - 1] + R::runif(-w, w);
    
    if (y <= 0.0 || y >= 1.0) {
      theta[i] = theta[i - 1];
      continue;
    }
    
    double logalpha = logpost_theta_cpp(y, n) - logpost_theta_cpp(theta[i - 1], n);
    double u = std::log(R::runif(0.0, 1.0));
    
    if (u < logalpha) {
      theta[i] = y;
      ++accept;
    } else {
      theta[i] = theta[i - 1];
    }
  }
  
  return List::create(
    Named("theta") = theta,
    Named("acc_rate") = static_cast<double>(accept) / (N - 1)
  );
}
